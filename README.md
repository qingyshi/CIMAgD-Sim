# Causally-interpretable meta-analysis using aggregate data

Simulation code accompanying the paper *Causally-interpretable meta-analysis using aggregate data* by Qingyang Shi, Wouter van Amsterdam, Sacha la Bastide-van Gemert, Talitha Feenstra, and Issa J. Dahabreh.

CIMAgD estimates a conditional average treatment effect (CATE) from aggregate randomized-trial reports: overall and one-at-a-time subgroup treatment effects, arm summaries, and baseline covariate summaries. It uses generalized method of moments estimation, then averages the fitted CATE over target-population covariates to estimate the target average treatment effect (ATE). The method is implemented in the separate [CIMAgD R package](https://github.com/qingyshi/CIMAgD).

These simulations assess finite-sample performance when treatment effects vary with covariates and trial populations differ from the target population. They compare CIMAgD with individual participant data (IPD) pseudo-outcome regression and the IPD g-formula; five-trial settings also include random-effects meta-analysis and meta-regression.

## Simulation settings

| Setting | Driver in `R/` | Overall sample size |
| --- | --- | --- |
| Single trial, binary outcome | `simstudy_1trial_binary_main.R` | 1,000 or 2,000 |
| Five trials, binary outcome | `simstudy_5trial_binary_main.R` | 5,000 |
| Single trial, continuous outcome | `simstudy_1trial_continuous_add.R` | 1,000 or 2,000 |
| Five smaller trials, binary outcome | `simstudy_5trial_binary_small_add.R` | 2,000 |

Sample sizes refer to the overall population before selection into trials; realized trial and target sizes are random. Each setting has 16 scenarios varying covariate distributions, selection, treatment-effect modification, and either overall sample size or allocation across trials. Full runs use 1,000 replications per scenario. Binary-outcome scenarios have a generally nonlinear true CATE fitted with a linear working CATE; the continuous-outcome scenarios have a correctly specified linear CATE.

Performance measures include bias, empirical variance, 95% confidence-interval coverage, mean squared error, mean absolute error, Monte Carlo standard errors, and fit failures. Evaluation uses a fixed population ATE calculated by Gaussian quadrature. Failed fits are recorded and are not replaced.

## Repository contents

- [`R/simulation_common.R`](R/simulation_common.R): shared scenario definitions, data generation, estimators, and execution.
- `R/simstudy_*.R`: the four simulation drivers listed above.
- [`R/summary_results.R`](R/summary_results.R): summaries, LaTeX tables, and figures from saved results.
- [`SIMULATION_RUN_GUIDE.txt`](SIMULATION_RUN_GUIDE.txt): installation, full runs, options, checkpoint recovery, and output details.

All data are generated by the scripts; no external study dataset is required.

## Quick start

Use R 4.1 or newer and install a compatible version of the CIMAgD package. Five-trial simulations also require `meta` and `metafor`; summarization requires `ggplot2` and `patchwork`. See the [running guide](SIMULATION_RUN_GUIDE.txt) for installation instructions.

Run these commands in a terminal **from the repository root**, the folder containing this README and `R/`:

```sh
# Small workflow check: 2 replications each for scenarios 1 and 16.
Rscript R/simstudy_1trial_binary_main.R

# Summarize the workflow check.
Rscript R/summary_results.R --input=results_smoke --output=simulation_summary_smoke

# Full single-trial binary simulation: all 16 scenarios, 1,000 replications each.
Rscript R/simstudy_1trial_binary_main.R --full --workers=4

# Summarize the available full-run results.
Rscript R/summary_results.R --input=results --output=simulation_summary
```

No-argument simulation runs are deliberately small and write to `results_smoke/<setting>/`; `--full` writes to `results/<setting>/`. Existing scenario files are protected unless `--overwrite` is supplied. Summarization replaces its output files, so use separate output folders for smoke and full runs. Generated result folders and local R/macOS session files are excluded from Git by `.gitignore`.
